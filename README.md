# Колонисты Парадайза — каталог игроков

Каталог персонажей LARP «Тишина Парадайза» для игроков: модули, фото, кратко о персонаже, общеизвестная легенда,
поиск по имени, правила и лор. Сделан в первую очередь для смартфона.

Каталог полностью автономный: он **не обращается к базе игры** и не содержит ключей доступа к ней.

## Что где лежит

- `index.html` — сам каталог.
- `catalog/data.json` — все данные каталога: модули и персонажи.
- `catalog/rules.md`, `catalog/lore.md` — правила и лор (Markdown).
- `catalog/photos/` — фото персонажей.
- `fonts/` — шрифты.

## Как править

Всё правится прямо на GitHub (карандаш «Edit» у файла) — через минуту изменения на сайте.

`catalog/data.json`:
- модуль: `id` (латиницей), `name`, `description`;
- персонаж: `id` (латиницей, он же ссылка `…/#id`), `name`, `module` (id модуля), `photo` (путь к фото),
  `tagline` (несколько слов), `legend` (общеизвестная легенда); `"hidden": true` — скрыть из каталога.
- Порядок в файле = порядок в каталоге. Новое фото — загрузить в `catalog/photos/` и указать путь в `photo`.

## Публикация

Settings → Pages → Deploy from a branch → `main`, папка `/ (root)`.
Ссылки: на персонажа — `…/#<id>`, на правила — `…/#rules`, на лор — `…/#lore`.
